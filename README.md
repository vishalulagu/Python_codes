# Python Codes

A collection of basic Python practice problems and mini projects.

## Project Structure

```text
python-code/
│
├── problems/                       # Basic Python logic and practice problems
│   ├── check_anagram.py            # Checks if two words are anagrams
│   ├── count_letter.py             # Counts character frequency in a word
│   ├── count_nums.py               # Counts frequency of numbers in a list
│   ├── find_duplicates.py          # Finds duplicate elements from a list
│   └── word_reverse.py             # Reverses word order in a sentence
│
├── simple_projects/                # Small utility and beginner projects
│   ├── qr_gen.py                   # Generates and saves QR codes as images
│   └── secret_trans.py             # Encrypts and decrypts secret messages
│
├── qrimgs/                         # Stores output generated QR code images
│   └── youtube.png                 # Sample generated QR code image
│
├── src/                            # Package source directory
│   └── python_code/
│       └── __init__.py             # Package initializer
│
├── .gitignore                      # Specifies files for Git to ignore
├── .python-version                 # Specifies Python version for the environment
├── pyproject.toml                  # Project configuration and dependencies
├── uv.lock                         # Pinned dependency lockfile
└── README.md                       # Project overview and structure documentation
```
